## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers a very broad range of cloud services covering computing, storage, databases, networking, security, analytics, and other areas. Its large service portfolio makes it suitable for many types of workloads and organizations.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. Organizations using Windows Server, Microsoft 365, and Microsoft identity technologies can extend their existing environment into Azure.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is particularly strong in artificial intelligence, machine learning, data analytics, and Kubernetes. Google Kubernetes Engine provides a managed Kubernetes platform for cloud-native applications.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Google Cloud because of its strong capabilities in artificial intelligence, data analytics, and Kubernetes. These technologies are useful for modern cloud applications and future development.
