# Cloud Provider Comparison

## Core Infrastructure Services

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID / Azure RBAC | Cloud IAM |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers a very broad range of cloud services covering compute, storage, databases, networking, security, analytics, and machine learning. Its wide range of services allows organizations to build different types of cloud applications using one provider.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

Microsoft Azure would be a suitable choice for an organization that primarily uses Microsoft products. Azure integrates closely with Microsoft's ecosystem and provides services that work well with Microsoft technologies.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud is widely recognized for its strengths in artificial intelligence, machine learning, and Kubernetes. Google developed Kubernetes and provides Google Kubernetes Engine (GKE) for managed Kubernetes workloads.

### 4. What similarities did you observe among the three cloud providers?

All three cloud providers offer services for computing, storage, networking, and identity management. They also provide scalable resources, security features, monitoring tools, and services for deploying applications in the cloud.

## Summary

AWS, Microsoft Azure, and Google Cloud Platform provide similar fundamental cloud infrastructure capabilities but use different service names and interfaces. Understanding equivalent services helps cloud engineers work with different cloud platforms.
