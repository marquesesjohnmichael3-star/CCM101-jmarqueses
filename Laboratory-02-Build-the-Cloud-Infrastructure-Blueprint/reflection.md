# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think compute resources are one of the most important cloud infrastructure components because they provide the processing power needed to run applications and services. Without CPU and memory, the system would not be able to process commands or perform tasks. In the KillerCoda environment, the CPU and RAM allowed me to run Linux commands and investigate the server.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a reliable operating system for servers and virtual machines. It also provides command-line tools that allow cloud engineers to inspect and manage system resources. In this activity, I used Linux commands to check the operating system, CPU, memory, storage, hostname, and network configuration.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it records the resources, configuration, and decisions related to an infrastructure design. It helps engineers understand the system and makes it easier to troubleshoot problems. Proper documentation also provides a reference before deploying actual cloud services.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux server and identify its compute, storage, networking, and operating system resources. I also learned how to organize technical information using Markdown and compare services from AWS, Microsoft Azure, and Google Cloud. I improved my Git and GitHub skills by managing my laboratory files and pushing changes to my repository.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio became more organized because I added a separate folder for Laboratory 02. It now contains technical documentation, system investigation results, cloud provider comparisons, screenshots, and a cloud architecture diagram. This makes my portfolio a better record of the cloud computing skills I have learned.
