# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform that provides services for computing, storage, networking, databases, security, artificial intelligence, application development, and enterprise workloads.

## Global Infrastructure

Azure operates a global cloud infrastructure made up of geographic regions and datacenters. This allows organizations to deploy applications closer to users and support requirements involving availability, performance, and data location.

## Cloud Management Console

The Azure Portal is a web-based management interface used to create, configure, monitor, and manage Azure resources and services.

## Four Core Services

1. Azure Virtual Machines – Virtual machines for running applications and workloads.
2. Azure Blob Storage – Object storage for unstructured data.
3. Azure SQL Database – Managed relational database service.
4. Microsoft Entra ID – Identity and access management.

## Three Advantages

1. Strong integration with Microsoft technologies.
2. Large global infrastructure.
3. Supports enterprise and hybrid cloud workloads.

## Typical Enterprise Use Cases

Azure can be used for Windows Server workloads, enterprise applications, databases, virtual machines, identity management, backup, hybrid cloud environments, and artificial intelligence workloads.
