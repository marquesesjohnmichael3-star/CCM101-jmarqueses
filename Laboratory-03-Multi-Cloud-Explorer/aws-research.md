# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides on-demand services for computing, storage, databases, networking, security, analytics, and other IT requirements.

## Global Infrastructure

AWS organizes its infrastructure into Regions and Availability Zones. Regions are separate geographic locations, while Availability Zones are isolated locations within a Region. This structure helps organizations build highly available and scalable applications.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services and resources. Users can create, configure, monitor, and manage cloud resources through the console.

## Four Core Services

1. Amazon EC2 – Virtual servers for running applications.
2. Amazon S3 – Scalable object storage.
3. Amazon RDS – Managed relational databases.
4. AWS IAM – Identity and access management.

## Three Advantages

1. Broad range of cloud services.
2. Scalable and highly available infrastructure.
3. Pay-as-you-go pricing model.

## Typical Enterprise Use Cases

AWS can be used for web application hosting, data storage, database management, backup and disaster recovery, analytics, and enterprise applications.
