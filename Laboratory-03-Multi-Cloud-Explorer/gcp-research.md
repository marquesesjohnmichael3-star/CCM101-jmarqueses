# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is a cloud computing platform that provides infrastructure, storage, databases, networking, artificial intelligence, analytics, containers, and application development services.

## Global Infrastructure

Google Cloud organizes its infrastructure into regions and zones. Resources can be deployed in different geographic locations to support performance, availability, and data location requirements.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to create, configure, monitor, and manage Google Cloud resources and services.

## Four Core Services

1. Compute Engine – Virtual machines.
2. Cloud Storage – Object storage.
3. Cloud SQL – Managed relational databases.
4. Google Kubernetes Engine (GKE) – Managed Kubernetes services.

## Three Advantages

1. Strong artificial intelligence and machine learning capabilities.
2. Strong Kubernetes support through GKE.
3. Scalable cloud infrastructure.

## Typical Enterprise Use Cases

Google Cloud can be used for artificial intelligence, machine learning, data analytics, web applications, virtual machines, containerized applications, databases, and global application deployments.
