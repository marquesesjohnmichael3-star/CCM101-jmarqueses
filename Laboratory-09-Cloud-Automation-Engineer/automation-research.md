# Automation Research

## 1. Bash Script

A Bash script is a file that contains Linux commands that can run in sequence. It helps automate repeated tasks instead of requiring a user to type every command manually. The `#!/bin/bash` line, called the shebang, tells the system to use Bash to interpret the script.

## 2. Variables

Variables store values that can be reused in a script. For example, `$BACKUP_DIR` represents the directory where backup files will be saved. Using variables makes a script easier to read and update because a value can be changed in one place instead of modifying several commands.

## 3. Cron Job

A Cron job is a scheduled task in Linux that runs a command automatically at a specified time or interval. It is useful in cloud operations because it can automate regular tasks such as backups, log cleanup, and maintenance. This reduces manual work and helps tasks run consistently.
