# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This activity explores object storage by deploying MinIO inside a Docker container. The deployment provides a simple S3-compatible storage service where a bucket can be created and files can be stored as objects.

## Objectives

- Compare the major types of cloud storage.
- Set up MinIO with Docker.
- Connect to the MinIO management interface.
- Create and use an object storage bucket.
- Upload a sample object.
- Record the completed work using Markdown.

## Tools Used

- KillerCoda Ubuntu Playground
- Docker
- MinIO
- GitHub
- Web Browser

## Skills Learned

This activity helped develop skills in Docker deployment, Linux command-line operations, object storage management, port forwarding, and GitHub documentation.
